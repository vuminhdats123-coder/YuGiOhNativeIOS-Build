# Real-core prompt acceptance scenarios

This historical report used the previous AI and fixtures that implicitly ORed
MR3 options into MR5. Current fixtures pass rule=0 and verify effective rules.
Their v7 regression passed; see [the correction and new evidence](HOST_RITUAL_PENDULUM_VALIDATION.md).

`host-prompt-validation.json` records six bounded scenarios generated by the
hash-pinned, precompiled Windows x86 OCG core. The production
`overlays/offline-ai/offline_ai.js` answers every prompt through its existing Node
adapter. No response packet is manufactured by the scenario harness.

The test-only Lua fixture, `../tests/fixtures/ocg_prompt_scenarios.lua`, creates
small fields using `Debug` and invokes actual `Duel` APIs. Each scenario succeeds
only after the core accepts responses and resumes Lua to emit its exact
`HINT_MESSAGE` completion marker. Lua assertions check resolved counter removal,
choices, and paid attack costs. The fixture never declares a duel winner and is
not included in the game bundle.

## Reproduce without compilation

From the repository root:

```powershell
python tests/test_ocg_matches.py
python tools/run_ocg_matches.py --prompt-scenarios --seed 201 --report outputs/ocg-reference/prompt-current.json
```

The harness checks the official portable Python archive, precompiled DLL, API
version, x86 ABI, pinned CDB, canonical Lua archive, and hashes of loaded runtime
scripts. It then relaunches under the verified 32-bit Python executable. Scenario
results default to `NativeClient/host-prompt-validation.json`, preserving the
existing full-match report. Test Lua and production AI/adapter hashes must remain
unchanged throughout the run. Each scenario has a 500-processing-step bound; the
isolated worker also has an outer timeout.

Twelve pure harness tests passed. After factoring the shared response helper,
one additional existing-deck regression match completed naturally: six turns,
216 responses, zero retries/errors, core win reason 1. That separate diagnostic
is in `outputs/ocg-reference/prompt-harness-regression.json`; it is not added to
the preserved 36-match report.
